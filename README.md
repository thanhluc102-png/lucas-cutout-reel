# Lucas Cutout Reel

Repository chuyên tạo video ngắn dạng **Product Cutout + Light Sheen Motion** cho **Lucas Combo** (`lucas.vn`).

## Đặc trưng thiết kế
- **Tách nền sản phẩm PNG Cutout (780px)** nổi bật ở vị trí trung tâm.
- **Hiệu ứng tia sáng chéo lướt qua sản phẩm (Light Sweep Sheen)** sử dụng `mask-image` bám 100% hình dáng sản phẩm.
- **Typography đồng nhất**: Sử dụng Google Font `Be Vietnam Pro` (`52px`, bold `800`) không bị lỗi font hay phình to lệch kích thước.
- **Header thương hiệu**: Logo Lucas Combo + `lucas.vn` viết thường.
- **Badge giá 3D**: Xoay nghiêng 6 độ nổi bật.

## Hướng dẫn sử dụng

```bash
npm install
npm run render
```
